# Product: AI Pager Station (AI 寻呼台)
Resurrects the 1990s pager (BP机) and the human pager-station operator as an AI. Users paste long messages, group-chat dumps or emails; the AI operator compresses each into a pager page of **max 20 characters**, optionally using classic numeric codes (520, 1314, 9958, 886, 7456, 555, 143, 911, 07734).
- Calm technology: only a few important pages per day (quota 5); low priority goes into one daily digest page.
- Must work fully with **no API key** (deterministic rule-based operator) so judges can run it.
- Bilingual EN / 中文. Nostalgic, playful, never preachy.
